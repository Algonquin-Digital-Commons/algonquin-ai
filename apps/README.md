# Applications

AI-adjacent integration and operator surfaces. Browser, desktop, and mobile
products release from their own repositories. No client connects directly to
model providers.

- `web/` — migration notice only; the browser client and gated Open WebUI
  source boundary belong to `algonquin-web` and its `psdc-web` upstream
- `code/` — thin downstream OpenCode integration, subject to release license review
- `admin/` — operational UI when the gateway needs one

See `algonquin-web`, `algonquin-desktop`, and `algonquin-mobile` for the
independently released institution client products.
