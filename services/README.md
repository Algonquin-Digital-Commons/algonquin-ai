# Services

The gateway begins as the modular platform kernel. Other directories describe
eventual service boundaries and should be extracted only when independent scaling,
security, deployment, or team ownership makes that worthwhile.

- Core: gateway, identity, model router, policy, usage, files, RAG, telemetry
- Academic: academic connector/knowledge capabilities
- Agent platform: student agent, tasks, notifications, action gateway, agent runtime
- Knowledge: campus graph and spatial context
